# Xiaozhe Fang — Personal academic website

A buildless English academic homepage, using HTML, CSS, and JavaScript. No package installation, paid theme, external font, analytics, or backend is required.

## Preview

Open `index.html` directly, or run `python -m http.server 8765 --bind 127.0.0.1` in this directory and visit `http://127.0.0.1:8765`.

## Edit

- `index.html`: biography, research, education, honors, contact details.
- `styles.css`: colors, typography, responsive layout.
- `script.js`: optional copy-email button and navigation highlighting.
- `assets/`: initials avatar, research image, manuscript, citation, and downloadable CV.

## GitHub Pages

Publish **only this `site` directory**, not its parent, which contains personal source materials and unrelated project files.

Use the repository `Abraham0206/Abraham0206.github.io`. In Settings → Pages, choose “Deploy from a branch”, branch `main`, folder `/ (root)`. The expected address after deployment is `https://abraham0206.github.io/`.
